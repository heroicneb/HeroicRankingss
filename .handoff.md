## Failed Approaches (Don't Repeat)

- **Empty-commit redeploy alone** to refresh stale siteSettings nav — didn't dislodge cached static routes. Force-dynamic on layout was the actual fix (`532b5d3`).
- **`runtime: "edge"` on `/api/chat` route** — build error: `"Route segment config 'runtime' is not compatible with nextConfig.experimental.useCache"`. Drop the export, default Node runtime works (`20f9b6e`).
- **Browser direct call to chatbot.heroicrankings.com** — 401 because backend now Bearer-gated. Must proxy via Vercel server route. Doc says "no exceptions."
- **Public token (`X-Site-Token: pub_…`)** — retired by chatbot owner. Only Bearer secret accepted now.
- **`vercel env add … preview`** without empty-string positional — CLI hangs on branch disambiguation. Use `vercel env add NAME preview "" --value "…" --yes` (empty string = "all branches").

## Key Decisions

| Decision | Rationale |
|---|---|
| Strict literal URL match (not 308 redirects) | Preserve all 102 legacy URL equity directly; ~95% < 100% via 308 |
| `/seo/[category]/[slug]/` dynamic route | Matches legacy `/seo/<cat>/<slug>/` pattern; `post.urlCategory` drives segment |

| Vercel proxy for chat (not direct) | Backend Bearer-gated; browser can't hold secret |
| Migrate 3 posts vs redirect | 7000 indexed words combined; 308 leaks ~5% equity |
