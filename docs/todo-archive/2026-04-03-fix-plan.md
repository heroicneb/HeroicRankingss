## Phase 8: Performance & Animation Optimization

### Task 8.1: Audit and optimize all animations

Read every animation component and verify:
- GPU-composited properties only (`transform`, `opacity`)
- `will-change` used sparingly
- `prefers-reduced-motion` respected everywhere
- No `setInterval` without cleanup
- CSS animations prefer `@keyframes` over JS
- `contain: layout` or `contain: paint` where appropriate

**Components:** `services.tsx`, `quote-rotator.tsx`, `trust-authority-rail.tsx`, `about.tsx`, `scroll-progress-bar.tsx`, `process-step-switcher.tsx`, `testimonials.tsx`, `mobile-menu.tsx`, `navbar-active-links.tsx`, `featured-logos.tsx`

### Task 8.2: Image optimization

- Convert remaining PNG/JPG to WebP
- Verify all raster images use `next/image` (not raw `<img>`)
- Add `priority` and `fetchPriority="high"` to hero images
- Add `loading="lazy"` to below-fold images
- Verify `width`/`height` attributes prevent CLS

### Task 8.3: Bundle optimization

- Run `pnpm build` and check bundle sizes
- Verify `"use client"` count matches ARCHITECTURE.md (16 files)
- Consider dynamic imports for large client components
- Verify DM Sans is self-hosted with `font-display: swap`

### Task 8.4: Core Web Vitals

- Run Lighthouse, target all scores >= 95
- Optimize LCP (hero image preload)
- Fix any CLS issues
- Check INP (no blocking handlers)
